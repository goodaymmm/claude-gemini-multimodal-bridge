🚀

v1.3.0 · New AI Studio Defaults

Off the access-restricted Gemini 2.5 line: gemini-3.5-flash-lite for general and document work, gemini-3.8-flash-tts for speech, gemini-3.1-flash-lite-image for images

📋

v1.3.0 · Antigravity Model Catalogue

The list of Antigravity CLI models CGMB knows about is refreshed

📄

v1.3.0 · PDFs Read Locally

A PDF with a text layer is sent to Gemini as text; scanned ones are still uploaded for OCR. This is the new default — --pdf-mode upload restores the old behaviour

🧹

v1.2.2 · Dead Code Removed

Four unreachable call paths and 740 lines of unused modules are gone; nothing users can reach behaves differently

🎯

v1.2.1 · Fix-Only Release

Concurrent AI Studio requests each get their own answer, cgmb exits when it is done, and .env is read from your project unless CGMB_ENV_PATH names another

🔄

v1.2.0 · Antigravity CLI

Web search moved off the discontinued Gemini CLI to agy, signed in through your OS keyring rather than an API key

📈 Performance

Cache
Repeated web-search prompts are answered from a result cache (ENABLE_CACHING, CACHE_TTL, MAX_CACHE_ENTRIES)
Lazy
Each layer starts on first use, not at startup; agy and Claude Code auth checks are cached for hours
Retry
Exponential backoff on transient API and CLI failures (MAX_RETRIES, RETRY_DELAY)

🚀 Quick Start

$ npm install -g claude-gemini-multimodal-bridge

💡 The postinstall script automatically:

  • Checks for the Antigravity CLI and prints install instructions if missing
  • Sets up Claude Code MCP integration
  • Creates .env template
  • Verifies system requirements

Then install the Antigravity CLI (agy 1.1.7 or newer) separately and run agy once to sign in. The token is stored in your OS keyring; there is no API key. Finally, add AI_STUDIO_API_KEY to a .env file in your project.
